# 审美判例

这份清单用于制作过程中和交付前逐条自检。它补充 `style-dna.md`，不替代画幅、隐私和技术规格检查。

## 节奏

- 关键信息落定后保留可读停顿。
- 主体动作弧至少约 3 秒；真实操作按真人速度。
- 速度感来自加速度和镜头关系，不来自匀速扫屏。
- 一种显眼动效全片只当一次主角。

## 画面

- 复刻已有页面必须使用真实截图或录屏。
- 真实 UI 的文字优先保持原生状态；作者新增文字必须满足字号和安全区规则。
- 3D 透视下的文字先检查源素材分辨率，再检查缩放方式。
- 信息密集镜头优先正视；侧拍和倾斜只服务于概念或物件表达。
- 扫光、粒子、闪白和相机抖动不能作为默认装饰。

## 声音

- BGM 先垫进成片试听，再决定是否保留。
- SFX 按动作和片种选择，不用游戏反馈音填空。
- 连发动作要避免机械复读。
- 画面时间线改变后，SFX 和旁白停顿全部重新核对。

## 文案

- 旁白具体、可验证、适合大声朗读。
- 标语优先写功能和收益，不用抽象隐喻代替事实。
- 不用小字、章节编号或英文副行弥补叙事不清。
- 画面、旁白、字幕三者各自承担明确职责。

## 输出格式

自检报告使用：

```text
R1 PASS
Q1 PASS
S1 PASS
C1 PASS
```

失败项必须附镜头名、帧号或文件路径，并回到对应阶段修复。
