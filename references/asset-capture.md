# 素材采集与安全边界

本文件约束真实网页、软件、终端、录屏、截图和官方素材的采集。素材采集必须服从项目 `AGENTS.md`、用户当前请求和已经确认的数据口径。

## 采集前检查

先写入 `design-spec.md` 和 `storyboard.md`：

- 素材要证明的具体旁白句子。
- 页面、路由、状态、交互动作和预期结果。
- 来源、授权状态、采集日期和是否可能过时。
- 数据口径：公开、虚构、脱敏或冻结。
- 是否需要用户确认、付费调用、登录权限或发布权限。

如果页面、命令、凭据或结果无法安全复现，停止在“素材缺口”记录，不用仿真画面伪造证据。

## 隐私和凭据

- 禁止在截图、录屏、终端输出、文件名和质量报告中出现 `.env`、API Key、Cookie、访问令牌、私有 URL、账号通知或个人资料。
- 登录页面只使用专门的演示账号或虚构数据；不使用用户的实时工作区作为默认素材源。
- 录屏前关闭通知、剪贴板预览、密码管理器弹窗和浏览器同步提示。
- 命令中的密钥参数替换成明确脱敏的示意值，例如 `<REDACTED_KEY>`。
- 声音样本、个人照片和私人素材只在有明确授权且确实需要时使用；交付物不展示样本本身。
- 采集前冻结实时数据，避免同一镜头在重渲染时内容漂移。

## 真实页面采集

复刻已有页面时，优先使用浏览器或应用的真实状态，不手搓近似 UI。建议为每个页面保留：

```text
media/<page>-fullpage@2x.png
media/<page>-<element>@2x.png
media/<page>-layout.json
media/<page>-capture-notes.md
```

`layout.json` 至少记录：

```json
{
  "viewport": {"width": 1920, "height": 1080, "deviceScaleFactor": 2},
  "elements": [
    {"id": "hero", "x": 120, "y": 160, "width": 840, "height": 420}
  ]
}
```

采集要求：

- 等待字体、图片和异步内容稳定；实时页面额外等待约 1.5–2 秒。
- 全页纹理使用 2x；3D 推近或文字特写使用 4x 切片或布局级放大。
- 保留关键动作前后约 1 秒余量，录下鼠标、点击、输入和结果出现。
- 记录浏览器、操作系统、页面版本、采集日期和可复现步骤。
- 只能把真实页面作为证据；抽象概念可以用作者绘制的图形，但必须标为概念图。

## 素材清单契约

每条素材必须有唯一编号，并能回溯到：

| 字段 | 要求 |
|---|---|
| 编号 | 稳定且唯一 |
| 文件 | 相对制作目录的路径 |
| 用途 | 要证明的句子或动作 |
| 来源 | 用户提供、官网、录屏、生成或公共素材 |
| 授权 | 明确许可、用户授权或待确认 |
| 数据口径 | 公开、虚构、脱敏或冻结 |
| 采集日期 | 真实日期 |
| 风险 | 过时、隐私、分辨率、版权或缺失 |

仓库参考工程的必需文件见 `assets/golden-reference/ASSET_MANIFEST.md`。该清单不是授权证明，实际素材仍需记录自己的来源和许可。

## 停止条件

出现以下任一情况时不要继续渲染：

- 证据需要登录但没有安全演示账号。
- 画面会暴露个人、客户、内部数据或密钥。
- 页面状态无法证明旁白结论。
- 素材授权不清楚，尤其是音乐、图片、字体和第三方界面。
- 竖屏或方形版式仍在使用未经重排的横屏素材布局。
