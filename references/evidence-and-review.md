# 内置证据与验收基线

本文件把原 `douyin-review-video-standard` 中与本技能相关的隐私、真实证据、节奏和验收要求内置到这里，并按 Infistar 风格和多画幅要求改写。使用本技能时不需要安装其他技能。

## 目标

把真实证据和连续旁白作为视频主体。用网页、软件操作、终端、模型输出、官方素材或动态素材承载叙事，用动态图形解释和强调证据；不得用长时间静态卡片代替视频。

## 叙事结构

- 0-3 秒：钩子。直接展示最强结果、异常现象或明确冲突，同时说明观众能得到什么结论。
- 3-10 秒：问题与判定标准。说明测试对象、核心问题和判断方式，避免品牌背景铺垫。
- 主体段：证据推进。按“操作-结果-解释-下一项测试”循环；每个结论必须有同步画面。
- 最后 15%-20%：结论。汇总优缺点、适合人群和明确判断。
- 最后 2-3 秒：自然收尾。延续当前画面结束，不另做静态结束页。

## 证据与画面

- 让操作录屏、模型输出、真实网页或其他动态证据占总时长约 65%-80%。
- 每 1-3 秒至少改变一次镜头信息：切镜、裁切、推拉、焦点、分屏、画中画、标注或新证据均可；无信息变化的装饰动画不计入。
- 不允许无叙事理由的近静止画面持续超过约 1 秒。静态素材不可替代时，持续使用缓慢推拉、局部追踪、遮罩揭示或逐项高亮。
- 动态图形只用于数字、结论、步骤和对比关系，单次尽量短于 3 秒；信息被理解后立即回到真实证据。
- 优先使用硬切、轻推拉和少量遮挡转场。不要在章节之间滥用全屏纸张擦除。
- 使用 J-cut 或 L-cut 让声音跨镜头连续；切镜不应打断完整语义单元。
- 同一素材二次出现时必须改变信息目的，例如从全景操作切到局部结果，而不是简单重复。

## 素材清单

每条素材至少写明：

| 字段 | 内容 |
|---|---|
| 编号 | 唯一素材编号 |
| 对应旁白 | 素材要证明的句子 |
| 画面 | 要录制或生成的具体内容 |
| 动作 | 点击、输入、滚动、对比或结果变化 |
| 建议时长 | 通常 2-8 秒，保留剪辑余量 |
| 来源 | 已有、用户补录、模型生成或公共素材 |
| 使用位置 | 时间轴区间或章节 |

录屏应隐藏账号隐私、通知和密钥。录制鼠标移动、点击、输入和结果出现的完整过程，并在关键动作前后各保留约 1 秒余量。

## 旁白与字幕

- 使用短句、动词和具体判断；删除书面化开场、空泛感叹和重复总结。
- 字幕每组约 7-14 个汉字，通常显示 0.8-1.8 秒，并跟随实际说话节奏更新。
- 每组只强调一个关键词、数字或结论；不要整句同时放大、变色或跳动。
- 字幕保持在该画幅的左右安全边距内，具体边距以 [视频形式](video-formats.md) 为准，并避开顶部大标题和底部关键 UI。
- 背景音乐只承担节奏，不盖过旁白；不得存在意外静音、爆音、截断或忽高忽低。

## 数据与隐私

- 遵守项目 `AGENTS.md` 和用户当前请求中的密钥、接口、输出目录与付费操作限制。
- 不显示 `.env`、密钥、账号通知、内部地址、个人数据或声音样本内容。
- 公开演示数据只有在确认公开属性后才可使用；客户、个人、内部、实时或其他敏感数据必须虚构、脱敏或冻结。
- 缺少支撑结论的录屏或模型输出时，先交付最小补录清单，不得用静态卡片填满缺口。

## 验收

- 成片画幅与 `design-spec.md` 一致；横屏 16:9 为 1920x1080，竖屏 9:16 为 1080x1920，方形 1:1 为 1080x1080，统一 30fps，分辨率至少 1080p。
- 真实动态证据占比约 65%-80%。
- 正常段落每 1-3 秒发生有效视觉变化，没有超过约 1 秒且无叙事用途的近静止画面。
- 字幕大多数符合 7-14 字、0.8-1.8 秒，并与旁白同步。
- 证据在对应结论说出时出现，没有口画错位。
- 没有黑帧、缺失素材、意外静音、字幕越界、界面隐私或密钥泄露。
- 关闭声音后仍能理解测试对象和核心结论；只听声音时叙事也连续。
- 最终必须通过本仓库的 `qa-checklist.md` 独立终检。
