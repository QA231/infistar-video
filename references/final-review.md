# 成片独立终检

独立终检必须由不参与制作的干净上下文执行。制作 Agent 自己的自检不能替代独立审查。

## 审查输入

只提供当前版本的：

- 成片和必要的无 BGM 版本。
- 开头、高风险镜头和结尾关键帧。
- `script-original.md`、`script-revised.md`、`script-edit-notes.md`。
- `design-spec.md`、`storyboard.md` 和素材清单。
- 当前版本的 `qa-checklist.md`。
- 使用的镜头卡、参考实现文件和授权记录。

不要提供“应该通过”的暗示、制作过程辩解或旧版本结论。

## 审查项目

### 文案与事实

- 旁白能自然朗读，没有明显 AI 套话、广告腔或空泛结尾。
- 人性化改写没有改变原意，也没有添加虚构经历、反馈、来源或测试结果。
- 事实、数字、版本、能力和比较都有证据或明确标记为待验证。
- 括号画面提示没有进入旁白或字幕，字幕与实际音频同步。

### 画面与素材

- 每个主要结论都出现同步证据。
- 真实 UI 原生文字与作者新增文字边界清楚。
- 没有眉题、英文副行、章节编号、步骤标签、装饰性小字或水印。
- 开头 10 秒至少有三次有效变化；没有黑帧、冻结、连续闪烁或无意义长停。
- 素材来源、授权、数据口径和采集日期可追溯。
- 没有密钥、个人资料、通知、内部地址或声音样本泄露。

### 工程与音频

- 选择的画幅、分辨率、帧率、字幕安全区和布局与 `design-spec.md` 一致。
- 参考工程仅用于它实际支持的画幅；没有把 16:9 绝对坐标直接拉伸到竖屏或方形。
- 所有静态素材和音频文件存在，文件名与 `ASSET_MANIFEST.md` 一致。
- BGM、SFX 和旁白没有截断、爆音、意外静音或明显错位。
- 使用 BGM 时，两版视频的画面和 SFX 逐帧一致，只有 BGM 开关不同。

## 报告格式

报告先给出：

```text
PASS
```

或：

```text
FAIL
```

每条问题必须附镜头名、帧号或文件路径，例如：

```text
FAIL
F2 FAIL 第 340 帧：旁白说到“导出设置”时没有对应真实界面。
C3 FAIL script-revised.md 第 12 行：加入了原稿没有的“我实测”经历。
Q4 FAIL assets/golden-reference/ASSET_MANIFEST.md：audio/keyboard.mp3 缺失。
```

任何 `FAIL` 都要返工、完整重渲并重新终检；不能把失败报告与未修复成片一起交付。
