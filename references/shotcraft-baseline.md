# Shotcraft 动效基线

本文件是 `video-shotcraft` 中与本技能相关内容的精简内置版本：自主自由创作路线、真实素材、镜头动效、声音设计和独立终检。上游项目与许可证见 `THIRD_PARTY_NOTICES.md`。使用本技能时不需要安装 `video-shotcraft`。

## 固定制作模式

本技能固定使用**自主自由创作**：输入足够时连续完成产品理解、视觉方向、镜头映射、分镜、素材、Remotion 实现、声音、渲染和终检，不逐阶段等待确认。用户当前请求和项目 `AGENTS.md` 始终是硬约束，不能覆盖。

## 执行阶段

1. **产品与约束**：只读判断主题、核心结论、目标受众、必须展示的证据、视觉线索、素材风险和数据口径。
2. **视觉方向**：用最多 3 个文字方向和一个纯 HTML/CSS 的 1920x1080 styleframe 锁定色板、字体、光感与动效性格；不写 Remotion 视频代码。
3. **镜头映射**：把口播稿中的每个叙事任务对应到一个镜头，并为每个镜头确定一个主要动效。
4. **分镜**：排出能量曲线，写帧级时间轴。每镜只讲一个主要动效，并预留 hold/rest 帧。
5. **最终素材采集**：按最终分镜采集真实证据，不提前做全量采集。
6. **逐镜头实现**：在 `assets/golden-reference/` 的已验收工程基础上适配，每镜头完成后用 Remotion still 抽帧自检。
7. **声音设计**：画面时间线锁定后才铺 BGM 和 SFX；SFX 钉在相对帧上。
8. **独立终检**：交给不参与制作的 subagent 审查，通过后才交付。

## 视觉语言

- 视觉必须从当前主题和已有产品/网页的真实设计系统生长，不另造一套无关的“宣传片皮肤”。
- 提取并写进 `design-spec.md`：字体、字重与字号层级、间距、栅格、圆角、背景/表面/正文/强调/状态色。
- 本技能覆盖为 16:9 清爽编辑风，具体 tokens 以 [风格 DNA](style-dna.md) 为准。
- 同一套动效 tokens 必须同时管理入场、转场和 hold 节奏；一个主题一种动效嗓音。

## 动效参数

按主题能量和调性选择，不凭手感乱挑 easing 或时长。起点表如下：

| 预设 | 主时长 @30fps | 入场 easing | 过冲 | squash |
|---|---|---|---|---|
| 专业信赖 | ~21f | bezier(0,0,0.2,1) | 1.0 | 0 |
| 精致高端 | ~48f | bezier(0.4,0,0.6,1) | <=1.02 | 0 |
| 活力大胆 | ~18f | bezier(0.16,1,0.3,1) | 1.12 | 0.25 |
| 活泼愉悦 | ~27f | bezier(0.34,1.56,0.64,1) | 1.08 | 0.18 |
| 平静关怀 | ~42f | ease-in-out 对称 | 1.0 | <=0.04 |
| 亲和友好 | ~26f | bezier(0.25,0.46,0.45,0.94) | 1.04 | 0.08 |

关键规则：

- 落地要弹的场合缓动 y1 必须大于 1；“专业信赖不弹”只适用于没有落地隐喻的淡入或推移。
- 批量元素入场靠运动本身，不靠逐个发光。装饰性 glint 或泛光群发是廉价信号，单点高质量光效可以保留。
- 每 1-3 秒有叙事意义的变化；关键信息落定后保留可读停顿。
- 品牌字标落定 hold 至少 1 秒，批量动效收尾至少静止 0.5 秒，开场主体动作至少 3 秒。
- 产品视频默认不加手持抖动；不逐帧随机；闪切不能造成连续闪烁。

## 真实素材

- 复刻既有页面必须用真实截图或录屏，不手搓近似界面。
- 最终素材三件套：全页 2x 截图、关键元素切片、记录 `{x,y,w,h}` 的 `layout.json`。
- 截图前等待字体和异步内容稳定；实时页面额外等待 1.5-2 秒。
- 真实页面优先放在浏览器或应用窗口中，用轻微推拉、聚焦、鼠标和键盘动作推进。
- 3D 推近时关键元素使用 4x 素材或 CSS `zoom` 布局级放大，避免文字发糊。
- 数据按项目口径冻结、虚构或脱敏后再采集。

## 镜头选择

默认复用 `assets/golden-reference/src/scenes/` 中已验收的浅色编辑镜头和 Shotcraft 深色动效镜头。新增镜头时必须：

- 先读对应已验收 TSX，不凭名称重写近似动画。
- 保留动作语法、关键时值、缓动关系和遮罩时机。
- 不得降低“已知坑/命门”标注的参数，质量标准只升不降。
- 在 `design-spec.md` 中记录新增镜头范围和验证风险。

## 确定性渲染

- 禁止 `Date.now()`、`Math.random()` 和无参 `new Date()`。
- 一切伪随机使用固定种子，seed 从 index 派生，保证逐帧可复现。
- 时间线、全局组件或素材改动后必须完整重渲，不拼接旧片段冒充整片。

## 声音

- 画面时间线锁定后才开始声音设计；画面改动后必须重对全部 SFX 帧号。
- BGM 只做能量底，不盖过旁白；默认交付带 BGM / 无 BGM（保留 SFX）两版，靠 `bgm` inputProp 从同一时间线导出。
- SFX 按镜头语言选择：运镜 whoosh、落地 impact、铺垫 riser、光效 light/sparkle、转场 transition、打字 text、翻页 paper。
- 禁用合成器 pluck/bloop、卡通弹跳等游戏提示音音色；真实点击、键盘、开关、碎裂仍要配拟音。
- `ui/` 类音效逐个试听，不能整目录放行；合成 confirmation/notify/tone 类默认不用。
- SFX 表集中管理，`from` 一律写相对表达式，例如 `SHOTS.x.from + offset`，不写裸数字帧号。
- 长样本超过 5 秒时显式给 `durationInFrames`，避免拖到后续镜头。
- 音量按素材实测峰值调整；轻音素材优先换同类高质量样本或预归一化，必要时给大于 1 的增益并在渲染产物中验峰防削波。
- 结尾句式固定为 riser -> impact -> sparkle。

## 独立终检

- 交付前派一个干净上下文的 subagent 做第三方审查。
- 只提供最新成片、关键帧、口播稿、设计 spec、分镜、素材口径和本仓库的 `qa-checklist.md`，不提供制作过程辩解或“应该通过”的暗示。
- 审查必须逐项出结论并附帧号或截图；任何必须修复项都返工、完整重渲并重新终检。
- 制作 Agent 自己出审查报告不可替代独立 subagent 终检。
