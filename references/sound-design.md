# 声音设计

声音是时间线级资产。画面结构基本锁定后再铺 BGM 和 SFX；任何镜头时长、顺序或动作变化都必须重新核对整张音频表。

## 旁白

- 用户明确说不要配音时，只做字幕、SFX 和用户允许的 BGM。
- 需要配音时，先完成 `script-revised.md`，再确认项目 `AGENTS.md` 中的声线、参考音频或已授权 voice ID 是否可被目标服务支持。
- 不臆造 voice ID，不把参考音频复制进仓库，不在日志或报告里展示声音样本内容。
- 付费配音、声音克隆和发布必须在调用前获得用户明确授权。
- 配音完成后，以实际音频重新计算字幕时长、停顿和 SFX 位置。

## BGM

- 用户指定音乐时，先分析 BPM、相位、能量段和主要瞬态；不要只相信播放器显示的 BPM。
- 用户未指定音乐时，按成片能量曲线选择，并记录曲名、URL、授权和下载日期。
- BGM 只托住节奏，不能盖住旁白和动作拟音。开头和结尾使用短淡入淡出。
- 启用 BGM 时，从同一时间线交付带 BGM 和无 BGM（保留 SFX）两版；未使用 BGM 时只交付一版。

## SFX

按镜头语言选择：

| 动作 | 优先音色 |
|---|---|
| 运镜和快速推拉 | whoosh |
| 落地、击打、字标定格 | impact |
| 结尾或大动作铺垫 | riser |
| 光效或轻量揭示 | sparkle/light |
| 场景切换 | transition |
| 真实点击、打字、开关 | 对应的真实物件拟音 |

合成器 pluck、bloop、卡通弹跳和 notification 反馈音默认不用。`ui/` 目录不能整目录放行，必须逐个试听并记录取舍；禁的是游戏提示音色，不是所有点击动作。

## 时间线约束

集中声明 SFX：

```ts
type Sfx = {
  from: number;
  src: string;
  volume: number;
  duration?: number;
  note: string;
};
```

- `from` 使用 `shot.from + offset` 或 `beatF(n)`，不写无法追溯的裸帧号。
- 长于 5 秒的样本显式设置 `duration`，避免拖进下一个镜头。
- 连发拟音使用双样本交替、音量阶梯递减和间隔加速，避免机械复读。
- 音量不能只看代码数字；渲染后检查峰值、削波、旁白清晰度和 BGM 遮蔽。
- 结尾可以采用 `riser -> impact -> sparkle`，但只有在分镜需要时使用。

## 音频记录

在 `storyboard.md` 或单独的 `audio-plan.md` 记录：

- 文件名、来源、授权、时长、峰值和用途。
- 每条 SFX 的目标动作和相对帧。
- BGM 淡入淡出和旁白 ducking 规则。
- 画面改动后是否完成全表重对。
