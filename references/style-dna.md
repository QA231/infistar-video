# 风格 DNA

## 视觉定位

关键词：清爽、可信、实测感、编辑感、产品演示、普通人能看懂。画面借鉴优质 AI 工具解说视频的节奏和信息组织，但不复制其他博主的品牌、片头、字体资产或独有包装。

### 色板

| 用途 | 建议值 |
|---|---|
| 深色背景 | `#08090B` / `#111318` |
| 暖白纸面 | `#F7F5EF` |
| 冷白表面 | `#F7F9FC` / `#FFFFFF` |
| 主文字 | `#16181D` |
| 主强调蓝 | `#4E78FF` |
| 深强调蓝 | `#3451B2` |
| 风险橙 | `#FF6B4A` |
| 次要线条 | 黑/白 10%–14% 透明度 |

浅色镜头以暖白、浅灰蓝渐变和低对比阴影为主；深色镜头用黑蓝底、克制的径向光和少量紫蓝环境光。避免大面积纯蓝背景、赛博霓虹、满屏粒子和玻璃拟态堆叠。

### 字体与层级

- 中文：`Microsoft YaHei UI`、`Noto Sans SC`、`PingFang SC` 的系统无衬线回退。
- 等宽：`Cascadia Mono`、`Consolas`，只用于终端或真实技术字段。
- 页面大标题：70–96px，字重 850 左右，行高 1.05–1.12。
- 卡片主文字：48–72px，居中或左对齐，卡片内只表达一个概念。
- 中文字幕：默认 60px、字重约 680、行高 1.24；有效字高不得低于 56px。
- 必要辅助文字：至少 32px，且必须承担功能。读不到的小字直接删除，不把它降级成装饰。

## 微文案禁令

这是本风格最重要的边界。

### 必须删除

- 标题上方的英文 eyebrow 或中文眉题。
- 大标题下方的英文 tagline、灰色解释句、蓝色补充句。
- 左上角 `01/02`、章节名、作者名、账号名或水印。
- 卡片中的小号步骤序号、模式副行、说明角标和 chip 式微标签。
- 信息图外围为了“显得专业”而加的小英文标签与连线说明。
- “CREATOR MODE / QUICK START / OFFICIAL DEMO”这类作者添加的小号说明。

### 可以保留

- 大标题、主卡片文字与中文字幕。
- 真实网页、软件、终端、表单、按钮中的原生文字。
- 为理解操作不可缺少且达到 32px 有效字高的功能文字。

判断法：如果删掉一行文字不影响观众理解画面动作，它就是装饰性小字，删除。

## 版式

下列数值是 16:9 横屏基线；竖屏和方形版式见 [视频形式](video-formats.md)。

- 画面安全边距：左右约 82–120px；主标题常位于左上 `x≈104–112, y≈126–146`。
- 字幕：左右 120px、底部约 68px，置于半透明圆角底板；进度线可置于底部 34px。
- 白底卡片：22–26px 圆角、1–2px 浅边框、柔和阴影；卡片数量通常 2–4 个。
- 深色 UI：使用真实页面或录屏置于浏览器/应用窗口，外加轻微推拉、聚焦和鼠标动作。
- 信息密集镜头正视；概念或物件镜头才使用轻微 2.5D 侧拍。

## 场景家族

按口播语义选择，不固定套满全部类型：

1. **钩子**：官方图标或一个大标题做唯一主角，2–3 秒内进入问题。
2. **三问题/三承诺**：浅色大卡片，只留主文字，不放序号和说明副行。
3. **纠正误解**：两张大卡片加划线/删除动作，随后出现真实产品标识。
4. **概念地图**：白底关系图或大号节点；节点文字必须够大，不加英文小标签。
5. **对比**：真实界面并排，顶部一个大结论；不堆参数小表格。
6. **章节击打**：纯白或纯深色背景，一个大词/大句快速落定。
7. **真实操作**：网页、终端、软件录屏，按鼠标/输入/结果出现推进。
8. **结构解释**：文件夹、工作区、流程或模式，用大号信息图解释关系。
9. **结论**：回到真实界面或暗场大结论，自然收尾；不另加小号“下期再见”字样。

## 动效与节奏

- 开场主体动作弧不少于约 3 秒；前 10 秒完成至少三次有效信息变化。
- 卡片入场使用非线性错峰，落定后至少保留 0.5–1 秒可读时间。
- 切镜以硬切、轻推拉、遮罩揭示和少量闪切为主。闪切不能造成连续闪烁。
- 产品宣传片默认零相机抖动。所有伪随机固定种子，禁止 `Math.random()` 与 `Date.now()`。
- 一种显眼动效全片只做一次主角。不要让每张卡片都扫光、发光或弹跳。
- 真实 UI 纹理优先 2x 截图；3D 推近时关键元素使用 4x 素材或 CSS `zoom` 路径，避免文字发糊。

## 字幕

- 根据标点切成每组约 7–14 个汉字，通常显示 0.8–1.8 秒。
- 一组最多强调一个关键词，强调色用主蓝。
- 口播稿括号里的画面提示不进入字幕。
- 未配音时仍按预计语速排字幕；配音完成后必须重新按实际音频对齐。
